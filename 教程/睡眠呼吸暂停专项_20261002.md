## 一、结论先行

**SA 是四个功能里唯一一个"卡在用户界面"而不是"卡在链路"的。** 血压和心电图是被
`shealth_monitor_base_app_setup_init` 挡住（已修），AGEs 是数据在传但指数未到门槛，
而 **SA 是手机端的激活问卷从来没被走过** —— 状态停在出厂默认值 `SELF_SELECTION`。

好消息：**入口已经帮你开在屏幕上了，点三下就能激活。**

### 2.5 年龄门不挡你

`SleepApneaCard.updateViewState()`（`outA/.../SleepApneaCard.smali`）：

```smali

move-result v0
invoke-static {v0}, Lcom/.../util/o;->X(I)Z   # true = 未满该年龄
move-result v0

```

17:41 实测：`SleepUtils.getRestrictionAgeBeforeOnboarding() = 22. Because it is SA1.0 phone`
→ restrictionAge = **22**（SA1.0 算法）。

而血压 deep-link 实测 `isValidAge = true`（= `o.X(22) == false` = 已满 22 岁）——
**同一套 `util/o.X()` 年龄判据，所以 SA 的 22 岁门槛对你不构成阻塞。**

SA1.0 / SA2.0 两代算法的年龄门不同：

| 代次 | 手机侧 | 手表侧 |
|---|---|---|
| SA 1.0 | **22 岁** | 22 岁 |
| SA 2.0 | 18 岁 | 18 岁 |

（代码里的判据是 `o.b0()` = 当前国家码是否在 SA2.0 支持白名单里。我们 spoof 成 `VN`，
日志显示走的是 **SA1.0 phone** 分支。）

## 三、SA 与「心律不齐通知」是两回事

SHM 首页底部三个 tab 是「睡眠呼吸暂停 / 血压 / 心电图」，但**第一个 tab 里同时住着两个功能**：

| | 睡眠呼吸暂停（SA） | 心律不齐通知（Ihrn / 房颤） |
|---|---|---|
| 包路径 | `sleep.view.*` / `sleep.v2.anlysis.breathingdisruption.*` | `ihrn.*` |
| 状态文件 | `SleepSharedPreferenceManager.xml` | `IhrnSharedPreferenceManager.xml` |
| 数据库 | `RoomSHealthMonitorIhrn.db` | `RoomSHealthMonitorIhrn.db`（共用） |
| 入口 | `sleep.view.activation.ActivationActivity` | `ihrn.view.onboarding.IhrnOnboardingSceneActivity` |
| 依赖 | 夜间佩戴 + 血氧/HRV 算法 | **依赖 ECG 数据**（`IhrnCard` 日志：`"ECG data exist"` / `"ECG data does not exist"`） |
| 当前状态 | `SELF_SELECTION`（未激活） | `IhrnDataCard: isOnBoardingFinished : true`（已完成） |

`IhrnSharedPreferenceManager.xml` 里的 `HAD_VALID_ECG_DATA` 键就是这个依赖的开关。
你在 19:43 测过 ECG（ECG 库暴涨 6 倍），**心律不齐通知这一块的前置条件已经具备**。

### 为什么选 `o.b0()` 而不是 `fk/h.n()`

`fk/h.n(RingChannel)` 的实现就是 `if (ch == SLEEP) return o.b0(); else false`，
所以 hook `o.b0()` **完全等价**，但：
1. `getDeclaredMethod("b0")` 无参，不必处理 `RingChannel` 参数类型，更稳
2. 已核实 `b0()` 的 **26 个调用点全部在 SA 相关代码里**
   （`SleepApneaCard`×4 / `SleepPromotionCard` / `SleepSwitchCardItem` / `Sleep2HelpActivity` /
   `SleepHistory` / `SleepLabelActivity` / `fk.h` / `vq.c` / 若干混淆类），**无一与 SA 无关**
3. 唯一副作用：`SleepUtils` 年龄门由 SA1.0(22 岁) 放宽到 SA2.0(18 岁)，方向更宽松，无害

## 六、优先级排序（四个功能合并视图）

| 优先级 | 功能 | 动作 | 状态 |
|---|---|---|---|
| **P0** | 血压 | 戴袖带实测一次，验证 `tracker_bloodpressure_accessory_data_count` 从 0 变 ≥1 | ⏳ 待测 |
| **P1** | 心电图 | 手表上发起一次 ECG（**你 19:43 已经测过一次，ECG 库已暴涨 6 倍，握手死锁确认解除**） | ✅ 已验证 |
| **P1** | **SA** | **点完诊断问卷激活**（页已开在屏幕上） | ⏳ **待点 3 下** |
| **P2** | AGEs | 打开 `tracker.age` 磁贴 + 连续佩戴入睡 3–5 晚 | ⏳ 待做 |
| **P2** | 心律不齐 | 前置 ECG 已具备，等 SA 激活后看是否出房颤记录 | ⏳ 被动 |
| **P3** | 保活 | v5 自愈（300s + SAP 守护）已部署运行 | ✅ |

> **SA 排在 ECG 之后**，不是因为不重要，而是因为它出结果需要「连续多晚佩戴」的长周期，
> 属于"点了激活就等数据"的类型，而血压/ECG 是"点一次立刻能验证闭环"的类型。
